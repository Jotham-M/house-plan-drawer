# House Plan Designer

A lightweight browser app for sketching floor plans using walls, room rectangles, labels, and SVG export.

## Features

- Draw walls by dragging on a snap-to-grid canvas
- Add room rectangles with dimensions and labels
- Place notes or area labels anywhere on the plan
- Delete objects with the erase tool
- Export the plan as an SVG file

## Run it locally

1. Open `index.html` in a browser.
2. Use the toolbar to switch tools.
3. Drag to create walls and rooms.
4. Click the export button to download the plan as SVG.

## File overview

- `index.html` — app structure and controls
- `styles.css` — layout and visual design
- `app.js` — drawing logic and interactions

## Notes

This is a front-end-only app with no backend or dependencies, so it's easy to modify and extend.
